# André Yuri — Personal Portfolio

Personal portfolio built with **React + JavaScript + CSS** using Vite

## Run locally

```bash
npm install
npm run dev
```

Then open the local URL shown by Vite.

## Build for production

```bash
npm run build
```

The production files will be generated inside `dist/`.

## Customize

Edit `src/App.jsx` to change:
- About text
- Skills
- Projects
- GitHub / LinkedIn links
- Education information

Edit `src/styles.css` to customize the visual theme.
